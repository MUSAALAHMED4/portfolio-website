🎨 Interactive Card Component

A modern, reusable JavaScript component with smooth animations

📝 Usage Instructions

Click on any card to flip it. Hover to see the elevation effect.

How to use this component:

// 1. Include the CSS and JS files
<link rel="stylesheet" href="css/interactive-card.css">
<script src="components/interactive-card.js"></script>

// 2. Create a container in your HTML
<div id="my-card-container"></div>

// 3. Initialize the component in JavaScript
const myCard = new InteractiveCard({
    containerId: 'my-card-container',
    title: 'My Card',
    description: 'This is a custom card!',
    icon: '🚀',
    primaryColor: '#6366f1',
    secondaryColor: '#8b5cf6'
});

// 4. Optional: Add theme toggle
const themeManager = new ThemeManager();
document.getElementById('toggleBtn').onclick = () => {
    themeManager.toggleTheme();
};
