# Musa ALAHMED · Portfolio

Personal portfolio website — a static site built with HTML, CSS, and JavaScript, featuring multi-language and theme (light/dark) support.

## Pages

- **Home** (`index.html`) — Introduction
- **About** (`hakkimda.html`) — Personal and professional background
- **Education** (`egitim.html`) — Academic background
- **Experience** (`deneyim.html`) — Work and volunteer experience
- **Portfolio** (`portfolyo.html`) — Projects
- **Contact** (`iletisim.html`) — Contact information

## Features

- Responsive design
- Light/dark theme toggle
- Multi-language support
- Animated background effects

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts (Poppins)
